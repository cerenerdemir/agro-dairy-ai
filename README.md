# 🌾 Agro-Dairy AI

Burdur Havzası Su, Enerji ve Rasyon Karar Destek Platformu

Süt verimini koruyarak yeraltı suyu ve kuyu elektriği tüketimini azaltan karar destek sistemi.

🔗 **Canlı uygulama:** https://agro-dairy-ai-cirk35g6f5tcmt8yd3hsdz.streamlit.app/

## Ne yapar?
- Mısır ağırlıklı üretimi, daha az su isteyen sorgum-sudan otu ve fiğ ile karşılaştırır
- Pompa enerjisini ve elektrik faturasını hesaplar
- Rasyon dengesiyle süt veriminin korunduğunu doğrular
- Çiftçiye gidecek SMS/WhatsApp mesajını ve teknik karar notunu üretir (Gemini)

## Yerelde çalıştırma
pip install -r requirements.txt
streamlit run app.py

## Not
Sonuçlar sentetik verilerle üretilmiş karar destek çıktısıdır. Nihai karar çiftçiye aittir.
